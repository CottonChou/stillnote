## 1. 移动端全屏图片预览跨笔记连续滑动与退出联动

### 交互设计
1. **跨笔记滑动切换**：
   - 当用户在全屏看图（`ZoomableImagePreview`）滑到当前笔记的最后一张图并继续向前滑（或在第一张向前滑）时，手势不会被阻尼生硬弹回，而是自动平滑过渡到当前工作区笔记列表中的**下一篇（或上一篇）含有图片的笔记**。
   - 自动跳过中间不含任何图片的纯文本笔记，直接无缝定位到相邻有图笔记的第一张（向后滑）或最后一张（向前滑）。
2. **顶部标题胶囊反馈**：
   - 顶部页码胶囊自动显示当前图片所属笔记的标题及在该笔记中的序号，例如：`「项目会议纪要」 · 1 / 3`，让用户在连续看图时对上下文一目了然。
3. **退出全屏笔记自动联动**：
   - 当用户退出图片预览（点击右上角关闭按钮或触发系统返回手势）时，主界面和笔记详情自动联动选中到**当前正浏览图片所属的目标笔记**。

### 核心实现
* **`apps/mobile/src/components/ZoomableImagePreview.tsx`**：
  * 支持 `onReachBoundary`、`canNavigateNext`、`canNavigatePrevious` 与 `noteTitle` 属性。
  * 在首末张图片处于边界时，根据是否支持跨笔记导航给予自然手势响应与滑出动画。
  * 顶部页码胶囊适配展示笔记标题与最大宽度保护。
* **`apps/mobile/src/screens/WorkspaceMemoDetail.tsx`**：
  * 结合本地 SQLite 镜像缓存，实现跨笔记图片检索与快速解码。
  * 维护预览笔记上下文，在退出全屏时联动更新选中笔记。

## 2. 移动端右滑引出笔记本抽屉侧边栏

### 交互设计
1. **右滑手势引出抽屉**：
   - 在笔记列表界面任意区域从左向右滑动（`translationX > 22`），即可平滑将笔记本导航抽屉引出。
   - 包含智能手势仲裁：纵向滑动超过 25px 优先交给笔记列表正常滚动，不会与普通浏览上下滑动手势产生冲突。
2. **左滑手势与点击背景收起**：
   - 抽屉处于展开状态时，向左滑动任意位置即可顺畅滑动收起，或点击半透明背景遮罩立即收回。
   - 响应 Android 系统物理/手势返回键（`hardwareBackPress`），按下返回键优先关闭展开的抽屉。
3. **导航与管理功能集成**：
   - **全部笔记**：一键切换回全部笔记视图，显示总笔记数量徽章。
   - **笔记本树形层级**：支持多级子笔记本缩进、一键展开/收起全部、当前选中高亮与对勾标记。
   - **快速搜索与新建**：内置笔记本名称实时模糊搜索过滤，支持行内快速新建子笔记本。
   - **回收站快捷入口**：底部设有回收站切换选项，打通移动端回收站与笔记本的无缝切换。

### 核心实现
* **`apps/mobile/src/screens/WorkspaceDrawer.tsx`**：
  * 实现 `useNotebookDrawer` 自定义动画与手势 Hook（`react-native-reanimated` 平滑阻尼弹簧动画）。
  * 全功能侧边栏抽屉组件与树状笔记本视图渲染。
* **`apps/mobile/src/screens/workspace-utils.ts`**：
  * 手势拖拽临界值判断算法 `resolveDrawerDrag`。

## 3. 移动端单篇笔记左滑快捷操作（星标、删除）

### 交互设计
1. **左滑手势与平滑展开**：
   - 在单个笔记卡片上向左滑（`translationX < 0`），卡片平滑滑出，露出右侧的两个操作按钮：
     - **星标（置顶 / 取消置顶）**：金黄色背景（`#d97706`），图标动态显示 `Sparkles`，文字根据当前笔记状态实时切换为「取消星标」或「星标」。
     - **删除**：红色背景（`#ef4444`），图标显示 `Trash2`，文字为「删除」。
   - 滑动位移阈值设定为 140px（两个按钮各 70px 宽度），支持平滑橡皮筋弹性阻尼。
2. **手势冲突保护**：
   - 纵向滑动保护：`failOffsetY([-20, 20])`，上下滑动滚动笔记列表时绝不会误触发卡片横滑。
   - 手势方向隔离：卡片向左滑与列表右滑呼出抽屉互不干扰。
3. **点击交互与状态自动闭合**：
   - 当卡片处于展开状态时，再次轻触卡片主体会立即收起按钮，而不会误进入笔记详情。
   - 点击「星标」或「删除」按钮后，卡片以弹性动画自动平滑归位。
4. **乐观更新与回收站保护**：
   - 点击星标：前端乐观更新 React Query 缓存中的 `pinned` 状态并异步调用 API，带来无卡顿瞬时反馈。
   - 点击删除：普通笔记本视图下立即从当前列表移除笔记并异步调用删除接口；回收站视图下弹出二次确认对话框，防止误删。

## 4. 元信息优先与按需同步架构

1. **轻量索引优先**：
   - 同步时优先拉取笔记本层级与笔记轻量元数据（ID、标题、标签、更新时间、摘要）；
   - 在数千条笔记规模下，几百毫秒内即可完成列表状态对齐。
2. **正文按需延迟加载**：
   - 笔记完整内容（`content_json` / `content_markdown`）在用户实际点击打开某篇笔记时按需载入并缓存在本地 SQLite 镜像中；
   - 支持单本手动同步（`Sync Notebook`）与全量同步，极大节省移动端流量与本地资源消耗。
